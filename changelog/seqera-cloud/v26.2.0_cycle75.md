## Feature updates and improvements

### Co-Scientist

- Replaced the **Recent** shortcut in the `@` mention menu with a **Search context** field, per-category browsing, paginated results, and status badges.

### Compute environments

- Added **Use private address** to Azure Batch Forge compute environments, for pool nodes without public IP addresses.
- Added the instance ID and failing command to setup script warnings in the run execution log.

### Studios

- Added a link from a Studio's details page to its compute environment.

### General

- Redesigned the organization, workspace, and user profile settings pages.

## Bug fixes

### Co-Scientist - projects

- Fixed the project **Datasets** tab showing unusable dataset actions to **Launch** users and non-functional buttons in empty projects.
- Fixed relaunching a run from a project's **Runs** tab returning to the workspace instead of the project.

### Pipelines

- Fixed **Launch** users being unable to resume runs of pipelines with **Pull latest** enabled.
- Fixed Azure data repositories selected as a run output directory producing an invalid path.
- Fixed a **Fusion version** selected in the launch form ignoring the compute environment's Fusion snapshots setting. A selected version with no Fusion snapshots build now fails the launch with an error.

### Compute environments

- Fixed AWS compute environments reporting an unexpected error instead of an access denial when credentials cannot reach the work directory bucket.

### Credentials

- Fixed Bitbucket Server credentials with an access token and no password being rejected when adding a pipeline or opening its launch form.

### Data Explorer

- Fixed the IGV preview losing its reference annotation track, chromosome ideogram, and gene name search.

### Data lineage

- Fixed selecting a task in global search results opening the run's **Tasks** tab instead of the task.

### Secrets

- Fixed pipeline secrets with underscores in their names being wrongly rejected as duplicates.

### General

- Fixed muted text using the light theme color in the dark theme.
- Fixed muted and raised surfaces being indistinguishable in the dark theme.
- Fixed pipeline and compute environment addresses in the public `12.0.0.0/8` and `172.32.0.0`-`172.37.255.255` ranges being rejected as private.
- Fixed screen readers not announcing a field's label together with its value.
