## Feature updates and improvements

### Projects

- Made **Projects** available in organization workspaces to roles with the **Projects** permission, which existing custom roles don't include.
- Added the **Project** workspace role, for a scientist who launches a project's pipelines, adds datasets, and reads run reports from the **Projects** view, without the workspace's Launchpad, Runs, Datasets, Compute, or Settings pages.
- Added a **Projects** permission category to custom roles.
- Surfaced `proj_` labels as projects in **Labels** settings.
- Limited the launch picker on a project's **Runs** tab to pipelines that carry the project's label.

### Pipelines

- Added a **Fusion version** selector to the launch form, and limited both version lists to compatible versions.

### Studios

- Added [Conda packages](https://docs.seqera.io/platform-cloud/studios/custom-envs) for custom container images under **More settings**.
- Shortened the browser tab title on the Studio details and connect pages to `Studio: <name>`.

### Data Explorer

- Added the bucket versioning state (**Enabled**, **Suspended**, **Disabled**, or **Unknown**) to the **About data repository** dialog for Amazon S3 and Google Cloud Storage data repositories.

### Data lineage

- Changed **See in Data Explorer** on the run **Outputs** tab to use the output directory from the run's lineage record.

### Credentials

- Added the **Set up Workload Identity Federation in GCP** panel to Google **Workload Identity** credentials created from the compute environment form.

### Monitoring

- Added a **Quick launch** action to the empty runs list.

## Bug fixes

### Projects

- Fixed notifications raised on **Projects** pages appearing below the page content and carrying over to the next page.
- Fixed the resource dialog opened from a project's **Runs** or **Datasets** tab discarding selections made on its other tab when saving.

### Co-Scientist

- Fixed the conversation selector hiding conversations not updated in the last three days, including from search.
- Fixed a Co-Scientist conversation link you don't have access to showing a generic load error instead of saying you lack access.

### Pipelines

- Fixed the **Add** and **Update** buttons on the action and pipeline forms staying disabled after a pipeline revision failed to load.

### Actions

- Fixed a paused action that names a deleted pipeline being resumable instead of asking you to point it at a live pipeline.

### Compute environments

- Fixed Azure Batch Forge compute environment creation accepting a malformed container registry credential ID, or more than one.

### Access control

- Fixed selecting a template for a custom role not applying its permissions.

### General

- Fixed a reached usage limit showing a warning icon instead of an error icon.
- Fixed the **Runs** and **All runs** pages showing no results when opened or reloaded with a search filter in the URL.
- Fixed cancelled runs showing an empty **Metrics** tab.
- Fixed the compute environment resources panel in the Studio creation form not filling the available width.
- Fixed copy buttons sitting lower than the value they copy.
- Fixed data chips with a copy button rendering taller than intended.
- Fixed the **Runs** page loading spinner appearing outside the page content area.
