## Feature updates and improvements

### General

- Consolidated installation capability toggles under `wave.capabilities.*` and added a `strict` environment that disables them all by @pditommaso in [#1098](https://github.com/seqeralabs/wave/pull/1098)
- Added the ability to disable the Wave direct image pull path so callers must use `freeze` mode by @gavinelder in [#1089](https://github.com/seqeralabs/wave/pull/1089)
- Reduced log noise from expected Platform-connectivity errors in the token watcher by @pditommaso in [#1085](https://github.com/seqeralabs/wave/pull/1085)
- Documented the workflow-bound ephemeral token lifecycle by @pditommaso in [#1084](https://github.com/seqeralabs/wave/pull/1084)

### Dependencies

- Upgraded Micronaut to 4.10.17 to patch `jackson-databind` (COMP-1957) by @cristianrcv in [#1091](https://github.com/seqeralabs/wave/pull/1091)

## Bug fixes

### General

- Fixed freeze and mirror images being served through the Wave proxy token path by @gavinelder in [#1087](https://github.com/seqeralabs/wave/pull/1087)
- Fixed the Wave release workflow to run only on `master` and `release-*` branches (DEVOPS-1531) by @ShahzebMahmood in [#1072](https://github.com/seqeralabs/wave/pull/1072)
