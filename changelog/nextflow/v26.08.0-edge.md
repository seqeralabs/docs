## Feature updates and improvements

### Language features

- Added an agent primitive to run AI agents as first-class Nextflow tasks by @pditommaso in [#7477](https://github.com/nextflow-io/nextflow/pull/7477)
- Added syntax error reporting for an unexpected character in a gstring by @bentsherman in [#7353](https://github.com/nextflow-io/nextflow/pull/7353)
- Updated the formatter to preserve comments by @ewels in [#7346](https://github.com/nextflow-io/nextflow/pull/7346)

### Configuration

- Added the `seqera.executor.maxCpusPerUser` config option by @jonmarti in [#7367](https://github.com/nextflow-io/nextflow/pull/7367)
- Added the `singularity.resourceLimits` config option by @bentsherman in [#7352](https://github.com/nextflow-io/nextflow/pull/7352)
- Split CLI config handling out of `ConfigBuilder` by @bentsherman in [#7373](https://github.com/nextflow-io/nextflow/pull/7373)

### S3

- Dropped transient object tags when publishing files to S3 by @pditommaso in [#7344](https://github.com/nextflow-io/nextflow/pull/7344)

### Kubernetes

- Treated a missing `k8s` config scope as an empty one by @pditommaso in [#7452](https://github.com/nextflow-io/nextflow/pull/7452)

### Plugins

- Aligned the Seqera executor `maxSpotAttempts` and Fusion handling by @pditommaso in [#7412](https://github.com/nextflow-io/nextflow/pull/7412)
- Bounded Seqera executor scheduler requests with a request timeout by @pditommaso in [#7466](https://github.com/nextflow-io/nextflow/pull/7466)
- Stopped fabricating a memory request for the Seqera executor by @pditommaso in [#7488](https://github.com/nextflow-io/nextflow/pull/7488)
- Used the Platform user identity for the Seqera executor `userName` label by @pditommaso in [#7413](https://github.com/nextflow-io/nextflow/pull/7413)
- Used registry config for plugin repos by @jorgee in [#7180](https://github.com/nextflow-io/nextflow/pull/7180)
