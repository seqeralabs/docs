## Feature updates and improvements

### Language features

- Added direct execution of named workflows by @jorgee in [#7379](https://github.com/nextflow-io/nextflow/pull/7379)
- Added workflow modules by @bentsherman in [#7342](https://github.com/nextflow-io/nextflow/pull/7342)
- Deprecated the `storeDir` directive and documented an alternative approach by @bentsherman in [#7574](https://github.com/nextflow-io/nextflow/pull/7574)

- Reported a syntax error for an invalid output or `emit` assignment by @bentsherman in [#7547](https://github.com/nextflow-io/nextflow/pull/7547)
- Reported an error for an aliased type include by @bentsherman in [#7557](https://github.com/nextflow-io/nextflow/pull/7557)
- Reported invalid escape sequences at the exact position by @bentsherman in [#7608](https://github.com/nextflow-io/nextflow/pull/7608)
