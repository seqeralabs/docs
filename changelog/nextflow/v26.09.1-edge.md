## Feature updates and improvements

### Language features

- Moved the type checker into `nf-lang` and brought static typing out of preview by @bentsherman in [#7656](https://github.com/nextflow-io/nextflow/pull/7656)

### Google Batch

- Deprecated Google Batch machine type selection via Cloud Info by @bentsherman in [#7677](https://github.com/nextflow-io/nextflow/pull/7677)

### Plugins

- Allowed a cache factory to decline a session by @jorgee in [#7681](https://github.com/nextflow-io/nextflow/pull/7681)

### General

- Added a hint to `nextflow log` and `nextflow clean` errors that the commands do not support the cloud cache by @bentsherman in [#7676](https://github.com/nextflow-io/nextflow/pull/7676)
- Removed a stray `git push` from the release task by @bentsherman in [#7678](https://github.com/nextflow-io/nextflow/pull/7678)

## Bug fixes

### S3

- Fixed S3 upload retries by making `ByteBufferInputStream` resettable by @jorgee in [#7577](https://github.com/nextflow-io/nextflow/pull/7577)

### Google Batch

- Fixed Google Batch array-child tasks reporting a null machine type by @pditommaso in [#7629](https://github.com/nextflow-io/nextflow/pull/7629)

- Bumped slf4j to 2.0.19 by @pditommaso in [#7661](https://github.com/nextflow-io/nextflow/pull/7661)
